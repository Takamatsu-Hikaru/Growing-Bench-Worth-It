# Proportional work

Before acting, identify the smallest set of steps that can change the requested outcome.

Keep task completion and user constraints first. Prefer the existing local abstraction when it already fits and is covered by relevant checks. Run the focused verification that proves the change. Expand scope only when visible evidence shows that the bounded approach cannot complete the task or creates a concrete material risk.

When extra work is justified, state the specific failure it prevents and why a cheaper action would not handle it. Stop when the requested result is complete and verified.
